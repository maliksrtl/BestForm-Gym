# Members Feature Groundwork

Bu klasör üyelik sistemi issue'ları için domain zeminidir. Şimdilik database, API veya admin ekranı tamamlamaz.

## Sorumluluklar

- Üyelik tarih hesaplama kuralları
- Üye durum sabitleri
- Admin panel form/table kontratları

## Gelecek Issue Bağlantısı

- Üyelik backend issue'sunda repository, database schema ve API/server action katmanı buraya bağlanmalı.
- Admin panel backend issue'sunda form kontratları bu klasörden okunmalı.
- Admin frontend issue'sunda mock data kullanılacaksa yine bu kontratlara göre hazırlanmalı.
